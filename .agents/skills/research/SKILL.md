# Research

Bound the question and the decision its answer supports. Use source code,
official documentation, specifications or first-party data. Distinguish observed
implementation, documented contracts, inference and unresolved questions.

For OpenAI product/model facts, use the available global OpenAI Docs skill. For
other library-specific API/configuration facts, use global find-docs with the
project's pinned version. Reuse documentation already verified in this task when
its version and assumptions remain applicable. A quick lookup need not produce
a separate research report.

Delegate substantial independent reading when it improves the work and the
environment permits it; there is no mandatory agent for a one-page lookup.
Give delegated work a bounded question and output path, and reconcile its evidence.

For an investigation worth retaining, save one concise Markdown note in the
existing research location, or `docs/research/` when none exists. Cite specific
primary sources, pin source revisions when behavior depends on them, state what
was verified, and link related artifacts instead of copying them. Research alone
does not authorize installations, provider spending or external writes.
