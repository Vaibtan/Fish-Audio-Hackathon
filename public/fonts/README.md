# Local fonts

Bungee Regular and Barlow Regular / Semibold / Bold are self-hosted so prepared
play needs no font-service connection. Their SIL Open Font Licenses are included.

Source: Google Fonts, downloaded 24 October 2026.

- https://fonts.google.com/specimen/Bungee
- https://fonts.google.com/specimen/Barlow
- https://github.com/google/fonts/tree/main/ofl/bungee
- https://github.com/google/fonts/tree/main/ofl/barlow

The adjacent TTF files are the unmodified Google Fonts static distributions.
